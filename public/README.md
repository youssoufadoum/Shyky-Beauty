# Shyky Beauty - Static Assets

This folder contains the static image assets for the Shyky Beauty website.

If you have your own product photos and branding image files, you can upload them directly into this folder using the file explorer in the AI Studio sidebar!

## Image Filenames Expected by the App

To ensure the website displays your images correctly, please upload them with the exact filenames listed below:

### 1. General Page Sections
- **`hero.jpg`** — The large main header banner image on the homepage (ideal size: 1200x800px or larger).
- **`about-1.jpg`** — The first image in the "About Us" story section.
- **`about-2.jpg`** — The second image in the "About Us" story section.
- **`contact.jpg`** — The background banner image shown next to the Contact form.

### 2. Product Showcase
- **`glossy-1.jpeg`** — Main product image for the "Lip Gloss Duo Pack".
- **`glossy-2.png`** — Second image display for Lip Gloss.
- **`glossy-3.jpeg`** — Third image display for Lip Gloss.
- **`glossy-4.png`** — Fourth image display for Lip Gloss.
- **`glossy-5.jpeg`** — Fifth image display for Lip Gloss.
- **`glossy-6.png`** — Sixth image display for Lip Gloss.
- **`liner-1.jpg`** — Main product image for the "Lip Liner 5 Shades" collection.

### Fallback System
The web app is equipped with an **automatic high-quality fallback system**. If any of these files are missing (due to not being committed or uploaded yet), the website will automatically load highly polished, themed beauty & cosmetics imagery from Unsplash. As soon as you upload a file with the corresponding name here, the app will instantly switch to display your real photo!
